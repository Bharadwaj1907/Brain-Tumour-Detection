# Brain Tumor Segmentation and Classification using 3D-CNN, Autoencoder, EfficientNet-B0

## Overview
This project is an AI-powered web application developed for brain tumor segmentation and classification using MRI images. The system uses Deep Learning models such as 3D Autoencoder, 3D CNN, and EfficientNet-B0 to detect and analyze tumors from brain MRI scans.

The application is deployed locally using Flask and provides an interactive web interface for uploading MRI scans and visualizing prediction results.



## Features
- Brain tumor segmentation
- Brain tumor classification
- MRI image preprocessing
- Tumor mask generation
- Tumor overlay visualization
- Deep Learning–based prediction system
- Flask web deployment
- User-friendly interface
